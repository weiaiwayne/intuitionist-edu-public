# Contributing

Use issues for questions and documentation corrections. Do not attach private conversations, study drafts, identifiable records, access tokens or server configuration.

This release is limited to framework and tech-stack documentation. Changes should preserve that scope and distinguish implemented mechanisms, design aims and empirical claims.

Proposed new files must be reviewed for rights and confidentiality and added deliberately to release-manifest.json with their content hash and license. Run `python3 tools/check_release.py` before proposing a release.

An external dataset or manuscript needs its own documented permission and release decision. A synthetic example should be labeled as constructed and should not be presented as evidence of actual system performance.

Contributions to code are offered under MIT; contributions to documentation and diagrams under CC BY 4.0, according to the scope in [LICENSE](LICENSE). Contributors must have the necessary rights to offer their material under those terms.
