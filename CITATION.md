# Citing IntuitionEDU

This repository describes the IntuitionEDU framework and tech stack. Cite the actual material you used and its version. Do not describe this documentation-only release as a validated empirical package.

Suggested descriptive citation:

> IntuitionEDU project. (2026). IntuitionEDU: A framework for human-directed agent teams in teaching and research [Framework documentation]. GitHub. https://github.com/weiaiwayne/intuitionist-edu-public

For a manuscript or proposal, add the release identifier or full commit SHA and access date. GitHub's citation display reads the accompanying [CITATION.cff](CITATION.cff).

A repository link is not an archival DOI. When an exact release is archived, add its real persistent identifier and update the citation metadata. Until then, no DOI is claimed.
