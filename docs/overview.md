# Project overview

IntuitionEDU investigates a practical question: can AI agents become useful collaborators in academic work when their responsibilities, evidence and decisions are inspectable?

The framework supports two areas. In teaching, agents can help prepare course plans, assignments, rubrics and reading suggestions. In research, they can help organize protocols, literature work, data analysis and replication. The human remains responsible for the question, access permissions, interpretation and release of the work.

The contribution is a way of organizing work across agents and time. A task has a brief, named participants, deliverables, review and an accountable decision. Artifacts preserve sources and revisions so a later reviewer can inspect how a conclusion arose.

## Goals

- Keep human decisions distinguishable from agent suggestions.
- Make methods, evidence and disagreements easy to inspect.
- Give repeated work a traceable correction process.
- Retain useful experience in editable memory and skills.
- Evaluate whether retained experience improves later decisions.

## Boundaries

The project is under development. This repository documents a framework; it does not establish general autonomy, reliable self-improvement, research validity, or a measured advantage over a single agent.

Agent roles are task assignments rather than permanent identities. A small team may use different model providers, but model diversity alone does not make judgments independent.

The framework does not replace disciplinary methods, research ethics review, data rights, human subject protections, or instructor responsibility.

## What readers can use now

Readers can examine the conceptual architecture and adapt the documented workflow. A researcher seeking executable replication should read [availability and reproducibility](reproducibility.md): this release does not contain the private orchestration system or empirical reproduction packages.
