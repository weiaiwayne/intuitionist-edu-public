# Project status

IntuitionEDU is an actively developed project for human-directed agent collaboration in teaching and research. The first public release documents its framework and tech stack.

## What is represented

The development approach uses an agent runtime, conversation-based interaction, task-scoped collaboration, file-based artifacts, human decisions, persistent memory and reusable skills. This repository provides a curated description of those concepts.

## What remains to demonstrate

A public executable distribution, independently reproducible empirical evaluation, reliable cross-task learning and general improvements over suitable baselines are not established by this documentation release.

Models, role assignments and implementation details can change. Older private planning documents are not a reliable statement of current capability. This public account deliberately avoids promises of perfect memory, autonomous scientific validity or guaranteed self-improvement.

## Planned release sequence

1. Framework and tech-stack documentation.
2. A separately reviewed minimal prototype, if selected for public release.
3. Reproduction packages for individual studies after authorship, rights, privacy and publication review.
4. Versioned archival snapshots for specific scholarly submissions.

Only the first stage is included here. Subsequent stages are plans, not available features.
