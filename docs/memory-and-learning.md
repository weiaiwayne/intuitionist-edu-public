# Memory and learning

IntuitionEDU distinguishes keeping information from learning to use it well.

| Object | Purpose | What it does not establish |
| --- | --- | --- |
| Task facts | Record what is known, proposed or uncertain | Permission to act beyond the brief |
| Human preferences | Preserve explicit choices and feedback | That an agent inference was approved |
| Research knowledge | Keep sources and relevant context | That every stored claim is correct |
| Reflection | Explain an outcome and propose a lesson | Improved future performance |
| Reusable skill | Describe a procedure or judgment practice with retrieval cues | Successful transfer to a different problem |
| Outcome record | Link a prior decision with later evidence | A causal benefit from the memory mechanism |

## Skills can be broader than scripts

A reusable skill may be a way to interpret evidence, recognize a methodological trap, frame uncertainty, coordinate work, or decide when to seek human input. Code can support these practices, but a script is not the whole skill.

A lesson should state when to retrieve it and when it would be inappropriate. For example, a rule about clustered observations should begin with identifying the analysis unit and dependence structure, not with insisting that one resampling method is always required.

## The proposed learning loop

Experience produces a record. Review produces a candidate lesson. Human governance determines whether and how the lesson enters a durable workflow. Later tasks test whether it is retrieved, applied correctly and useful.

The development project has mechanisms for persistent files and feedback records. This public release does not publish the private records or claim a measured causal effect from them. The stronger claim—better decisions because of retained experience—requires evaluation.

## Evaluation questions

Was the lesson retrieved in an appropriate context? Did it change the decision? Was the change supported by later evidence? Did the lesson transfer beyond its originating example? Did it create new errors or unnecessary overhead?

A constructed transfer exercise can reveal understanding. A later real assignment provides stronger evidence of reuse. Neither should be represented as proof of generalized self-improvement.
