# Security and sensitive information

This documentation repository contains no deployed service and requests no credentials.

Do not post suspected live secrets or private records in a public issue. For a sensitive report, use the repository's private security-reporting feature if enabled, or arrange a private channel with the maintainer. If no private channel is available, ask only for contact instructions and omit the sensitive content.

The release checker detects some unexpected files and recognizable secret patterns. It is not a security audit or a substitute for human review.
